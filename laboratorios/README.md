# Planejamento por laboratórios

A pasta organiza a captação a partir das necessidades acadêmicas, evitando duplicidade de pedidos.

- `matriz_laboratorio_empresa.csv`: empresas capazes de atender cada eixo;
- `plano_modernizacao_por_laboratorio.md`: escopo técnico e níveis de atendimento.

A matriz deve ser revisada quando novos equipamentos forem recebidos ou quando o DEE alterar suas prioridades.
