# Modelos de ofícios por empresa

Esta pasta contém 30 modelos LaTeX personalizados para prospecção de doações e parcerias para o DEE/IFMA.

## Compilação no Overleaf

Cada arquivo numerado (`01_...tex` a `30_...tex`) é agora um documento LaTeX completo e pode ser selecionado diretamente como **Main document** no Overleaf.

Passos:
1. Abra **Menu** no Overleaf;
2. Em **Main document**, selecione o arquivo da empresa desejada, por exemplo `empresas/01_schneider_electric.tex`;
3. Use compilador **pdfLaTeX**;
4. Clique em **Recompile**.

O arquivo `base_empresa.tex` contém apenas o corpo comum dos ofícios e não deve ser escolhido como documento principal.

Todos os modelos usam o padrão visual definido em `modelos/preambulo.tex`.
